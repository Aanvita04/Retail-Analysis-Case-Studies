## Overview 
This project analyses two datasets using machine learning algorithms to gain insights on customer behaviour and overall retail operations. 

## Datasets 
- Online Retail Customer Churn Dataset
- Retail Inventory Optimization Dataset

## Machine learning Models 
- Decision Tree
- Support Vector Machine (SVM)

## Files 
- `Retail_Analysis.ipynb` – Jupyter Notebook containing data preprocessing, model implementation, and evaluation.
- `online_retail_customer_churn.csv` – Customer churn dataset.
- `retail_sales.csv` – Retail sales dataset

## Techstack
- Python
- Pandas
- Numpy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
